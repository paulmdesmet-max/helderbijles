# HelderBijles website versie 2

Open `index.html` in een browser om de nieuwe website te bekijken. Alle beelden staan lokaal in `assets/`, dus zij zijn niet afhankelijk van externe websites of browserextensies.

Het contactformulier is nog een veilig prototype en stuurt geen gegevens door. Koppel het pas bij publicatie aan een definitieve mailbox of formulierdienst, samen met een privacyverklaring.
